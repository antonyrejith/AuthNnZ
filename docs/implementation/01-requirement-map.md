# 01 — Requirement Map

Every one of the 298 catalog features is assigned to exactly one build increment (the increment in which it is completed) and a verification class. This file is generated by a script that fails if any feature is missing, duplicated or unknown.

**Verification classes**

| Class | Meaning |
|-------|---------|
| **L** | Verified here by automated tests, including tests against our own services in containers |
| **E** | Verified here against a local emulator or container of the third-party counterpart (for example Keycloak as a SAML/OIDC partner, OpenLDAP, Mailpit, OpenBao, a test ACME server) |
| **X** | Needs an external service or credentials (cloud accounts, SMS, KYC, CAPTCHA, marketplaces, SaaS APIs, an LLM API key). Implemented against the provider's documented API and covered by contract tests; **live verification pending** until credentials exist |
| **T** | Needs a toolchain not available in this environment (Xcode for iOS, the Android SDK, .NET, Unity, Unreal). Built and verified only when such an environment is attached |
